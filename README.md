# Zing Star Inspector

เว็บไซต์บริษัท ซิง สตาร์ เอนจิเนียริ่ง แอนด์ คอนสตรัคชั่น จำกัด
บริการตรวจบ้าน ตรวจคอนโด ตรวจทาวน์โฮม โดยวิศวกรมีใบประกอบวิชาชีพ

เว็บจริง <https://zingstarengineering.com>

## โครงสร้าง

static ล้วน ไม่มี build step ไม่ต้อง `npm install` push ขึ้น `main` แล้ว Cloudflare Pages
สร้างใหม่เองภายในประมาณหนึ่งนาที

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | หน้าเว็บจริง HTML CSS JS อยู่ในไฟล์เดียว |
| `base.html` | ฝาแฝดที่เก็บไว้อ้างอิง ต้องมีค่าบริการตรงกับ `index.html` เสมอ |
| `data/site.json` | **ข้อมูลจริงของค่าบริการ** ป้ายโปร แถบข้อความ และหมายเหตุ |
| `admin/` | หน้าจัดการค่าบริการ ดูหัวข้อถัดไป |
| `tools/verify-render.mjs` | ตรวจว่าโค้ดสร้าง HTML ได้ตรงกับไฟล์จริง |
| `_headers` | หัวข้อความปลอดภัยที่ Cloudflare Pages ส่งให้เบราว์เซอร์ |
| `img/` | รูปและวิดีโอทั้งหมด ประมาณ 16 MB |

## ค่าบริการแก้ที่ไหน

**`data/site.json` ที่เดียว** ห้ามแก้ HTML ในตารางราคาด้วยมือ

ส่วนราคาใน `index.html` และ `base.html` ถูกคร่อมด้วยคอมเมนต์

```html
<!--ZS:TABLES-->
   ...ตรงนี้ถูกสร้างจาก data/site.json...
<!--/ZS:TABLES-->
```

มีห้าบล็อก `PROMO` `TABS` `BANNER` `TABLES` `NOTES` ทุกอย่างนอกบล็อกไม่มีอะไรแตะ

### แก้ผ่านหน้าเว็บ

<https://zingstarengineering.com/admin/> แก้ในฟอร์ม กดเผยแพร่ แล้วเว็บอัปเดตเอง
ต้องใช้ GitHub fine-grained token ที่มีสิทธิ์ Contents เขียนคลังนี้ ดูวิธีสร้างในคู่มือส่งมอบงาน

หน้านี้ไม่เก็บรหัสอะไรไว้ในตัวเอง รหัสที่กรอกอยู่ในแท็บนั้นชั่วคราว ปิดแท็บแล้วหาย
และถูกล็อกด้วย CSP ให้ติดต่อออกไปได้เฉพาะ `api.github.com` เท่านั้น

### แก้จากเครื่อง

```bash
node tools/verify-render.mjs --write
```

อ่าน `data/site.json` แล้วเขียนทับเฉพาะในบล็อก `ZS:` ของทั้งสองไฟล์
ถ้าไม่ใส่ `--write` จะเป็นแค่การตรวจ ผ่านคือไฟล์ตรงกับข้อมูลอยู่แล้ว

รันคำสั่งนี้ก่อน commit ทุกครั้งที่แตะ `data/site.json`

## คลังโค้ด

| ที่ | ใช้ทำอะไร |
|---|---|
| `zingstarengineering-stack/zingstar-engineering-site` | ตัวจริง Cloudflare Pages build จากตัวนี้ หน้า admin เขียนลงตัวนี้ |
| `SPNpeet/zingstar-engineering` | สำเนาสำหรับพัฒนา |

หน้า admin เขียนลงคลังตัวจริงเท่านั้น ถ้าเจ้าของแก้ราคาผ่านหน้าเว็บไป
ก่อนจะทำงานต่อจากเครื่องต้อง `git pull client main` ก่อน ไม่งั้นงานจะชนกัน

## Deploy

```bash
git push origin main   # สำเนา
git push client main   # ตัวจริง ตัวนี้ทำให้เว็บอัปเดต
```

แก้ราคาแล้วอยากให้คนที่เคยเข้าเว็บเห็นของใหม่ทันที ต้องเข้า Cloudflare
แล้วสั่ง Purge Everything ด้วย เพราะ Browser Cache TTL ตั้งไว้ 4 ชั่วโมง
