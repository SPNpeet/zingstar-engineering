# Zing Star Inspector

เว็บไซต์บริษัท ซิง สตาร์ เอนจิเนียริ่ง แอนด์ คอนสตรัคชั่น จำกัด
บริการตรวจบ้าน ตรวจคอนโด ตรวจทาวน์โฮม โดยวิศวกรมีใบประกอบวิชาชีพ

## โครงสร้าง

เป็นเว็บ static ล้วน ไม่มี build step ไม่ต้องติดตั้งอะไร

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | หน้าเว็บจริงที่ใช้งาน — HTML, CSS, JS อยู่ในไฟล์เดียว |
| `base.html` | เวอร์ชันตั้งต้นที่เก็บไว้อ้างอิง ราคาตรงกับ `index.html` |
| `img/` | รูปภาพและวิดีโอทั้งหมด (~16 MB) |
| `.nojekyll` | บอก GitHub Pages ว่าไม่ต้องประมวลผลผ่าน Jekyll |

## แก้ราคา

ตารางราคาอยู่ใน `index.html` ส่วน `<section id="pricing">` แบ่งเป็น 3 ตาราง
คอนโด (`#p-condo`) ทาวน์โฮม (`#p-town`) บ้าน (`#p-house`)

รูปแบบแต่ละช่อง

```html
<span class="was">ราคาเดิมขีดฆ่า</span><span class="now">ราคาโปร</span>
```

ป้ายเดือนโปรโมชั่นอยู่ที่ `<span class="promo-pill">` เหนือตาราง
แก้ราคาแล้วต้องแก้ใน `base.html` ให้ตรงกันด้วย

## Deploy

Pages ตั้ง source เป็น branch `main` โฟลเดอร์ `/(root)`
push ขึ้น `main` แล้วเว็บอัปเดตเอง ไม่ต้องรันคำสั่งอะไรเพิ่ม
